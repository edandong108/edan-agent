# spec · 【功能名】

> 这是功能的**行为契约**，是技术方案、测试方案、评审一页纸的共同源头。
> 写法：描述系统**该做什么**，不描述**怎么实现**。每条行为契约必须可测。

## 功能概述

一句话：做什么、给谁用、解决什么痛点。

## 行为契约

> 格式：当 X 时，系统应 Y。每条可测，是测试用例的源头。

1. 当 ... 时，系统应 ...
2. 当 ... 时，系统应 ...

## 边界与约束

- **输入**：格式 / 来源 / 必填项
- **容量/性能**：单次上限 / 响应时间
- **失败处理**：部分失败策略 / 事务边界 / 重试
- **权限**：谁能操作 / 越权处理

## 非目标

> 明确不做什么，防止 scope 蔓延。

- 不做 ...
- 不做 ...
