> 编制：数据应用小组 · 2026-09-09（同步实现变更）· 依据 `test-creator` 技能方法论
> 关联：[评审一页纸](../方案/离线作业队列状态查询-评审一页纸.html) · [技术实施方案](../方案/离线作业队列状态查询-技术实施方案.html) · [上线配置](../方案/离线作业队列状态查询-上线配置与联调对账.md)

## 一、需求分析

### 被测对象与范围

两个**只读**页面，数据来自已有 `schedule_queue`（append-only 历史）+ `job_instance` + `job`，不参与调度、不写库、不联动动作。

- **入口**：【数据交换】→ **任务运维** → Tab「队列状态」/「队列分析」。
- **队列状态 Tab**：当前/历史时刻三态快照（统计卡 + 明细表）。
- **队列分析 Tab**：按天 5 分钟切片（288 片）的 KPI、趋势图、按小时表、TopN。

### 关键风险点

1. `schedule_queue` 字段名与 `status` 枚举值未与底层老师对齐 → 快照重建 SQL 口径可能偏差。
2. 僵尸心跳阈值 100s 的来源（配置 / 硬编码）未确认。
3. 10s 自动刷新对元数据库压力未量化。
4. 历史快照为"尽力重建"，非精确记录，验收口径需对齐。

### 需求质量审查结论

| 维度 | 结论 |
| ---- | ---- |
| 完整性 | 🟡 `schedule_queue` 字段语义待确认；僵尸阈值来源待确认 |
| 一致性 | 🟢 湖表名取法（出湖 source / 入湖 target）与台账页一致 |
| 清晰度 | 🟢 SLA 基线 30min、历史精度到分钟、Top10 可分页 均明确 |
| 可测试性 | 🟢 三态判定、切片聚合口径、去重规则 均可设计确定步骤 |
| 性能/安全 | 🟡 10s 刷新压力未量化；无性能 SLA 基线；安全为内部只读页（权限为主） |

### 待确认问题

- ❓ [待确认] `schedule_queue` 实际字段名（`finished_at` 是否叫 `dequeue_time`？）、`status` 枚举值（QUEUED/SUBMITTED/...）。
- ❓ [待确认] 僵尸心跳阈值 100s 取自配置还是硬编码？是否可配？
- ❓ [待确认] `submit_time` 索引是否存在（影响聚合查询性能）。
- ❓ [待确认] 历史快照"尽力重建"的允许误差范围（验收基线）。

## 二、功能拆解

### 功能模块树

```
任务运维（taskOperations）
├─ Tab：队列状态（快照）
│  ├─ 时间模式切换（当前/历史）
│  ├─ 当前时刻快照
│  ├─ 历史时刻快照（精度到分钟）
│  ├─ 三态展示（排队中/执行中/僵尸）
│  ├─ 跨集合去重
│  └─ 自动刷新（10s 可选）
├─ Tab：队列分析（趋势）
│  ├─ 筛选条件（日期/优先级/切片粒度）
│  ├─ KPI 卡（5 个）
│  ├─ 图表（4 张 SliceChart）
│  ├─ 按小时聚合表
│  └─ TopN 积压作业（Top10 可分页）
└─ 公共
   ├─ 权限控制（只读）
   ├─ 范围说明文案
   └─ 时钟基准（DB NOW()）
```

### 系统形态识别

| 形态 | 是否启用 | 说明 |
| ---- | -------- | ---- |
| Web 端 | ✅ 启用 | 兼容性、易用性 |
| 接口 | ✅ 启用 | snapshot、analyze 两个 GET 接口 |
| 性能 | ✅ 启用 | 聚合查询、自动刷新压力 |
| 安全 | ✅ 启用 | 内部只读页，OWASP 轻量（注入/越权基础覆盖） |
| 权限 | ⚪ 系统控制 | 由 IAM 单独管理，不在本用例集单独覆盖 |
| 移动端 | ❌ 未启用 | 无移动端需求 |
| AI/算法 | ❌ 未启用 | 无 AI 能力 |
| 数据迁移 | ❌ 未启用 | 非迁移场景 |
| 灰度发布 | ❌ 未启用 | 随 SLA 第一阶段一起发布 |
| ERP | ❌ 未启用 | 非ERP系统 |
| 自动化脚本 | ❌ 未启用 | 用户未明确要求（可后续按需生成） |

## 三、测试点分析

### 队列状态页

| 维度 | 测试点 |
| ---- | ------ |
| 页面 | 加载、三段统计卡布局、明细表渲染、空数据 |
| 时间切换 | 当前/历史切换、历史选择器启用/禁用、精度到分钟 |
| 当前态 | 三态数量正确、明细字段正确、10s 刷新数据更新 |
| 历史态 | 选未来时间报错、过去时间重建正确、静态不刷新 |
| 去重 | 同一 jobId 跨集合只归一侧、集内取最新实例 |
| 范围 | 非队列提交作业不在快照、顶部文案提示 |

### 队列分析页

| 维度 | 测试点 |
| ---- | ------ |
| 筛选 | 日期、优先级、切片粒度（5min/1hour）切换联动 |
| KPI | 5 个 KPI 卡数值正确、高优/普通达标率口径 |
| 图表 | 4 张趋势图渲染（time 轴、整数刻度）；联动/参考线一期未做 |
| 按小时表 | 24 行数据正确、超基线标红 |
| TopN | Top10 排序、分页、优先级筛选生效 |

### 公共

| 维度 | 测试点 |
| ---- | ------ |
| 菜单可见性 | IAM 菜单控制入口；只读无编辑 |
| 时钟 | 当前态以 DB NOW() 为准、历史态 ≤ NOW() |
| 异常 | 接口超时、DB 不可达、空数据 |

### 核心业务链路（P0/P1 聚焦）

1. **当前时刻快照查看**：任务运维 → 队列状态 Tab → 默认当前态 → 三态正确（P0）
2. **历史时刻快照回看**：切历史态 → 选某分钟 → 查询 → 重建快照正确（P1）
3. **按天队列分析**：队列分析 Tab → 选日期 → KPI + 图表 + TopN 正确（P0）
4. **指标口径提示**：各 KPI/列头/图表标题 ⓘ 与文档口径一致（P2）
